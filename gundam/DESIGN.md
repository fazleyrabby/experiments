# RX-78-2 viewer

The final direction follows the user's reference and requested simplification: a centered mecha, dark studio, and only Break down and Assemble buttons. No titles, descriptive copy, status panels, sliders, tabs or decorative interface elements. Assembly announcements remain available to screen readers.

Native CSS and Three.js. Narrow square-cornered controls, cool neutral text and dark surfaces. The model carries the white, blue, red and gold palette, white V-fins and amber eyes of the supplied reference. Detailed armor geometry and actual mechanical components provide the visual density. Instancing reduces rendering cost without sacrificing independently animated parts.

The camera centers the model in normal and exploded states, widening for armor separation. Pointer input interrupts camera motion. Reduced motion skips the opening sequence and makes assembly changes immediate. Mobile preserves the same two-button interface.

Layers: scene 0, controls 1, loading/error 2.
