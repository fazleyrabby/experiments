# Highland Express

A fully procedural 3D steam-railway diorama: a Victorian 4-6-2 locomotive and four coaches
crossing a nine-arch curved stone viaduct high above a Scottish Highland glen, in the low light of
a late-summer afternoon.

Everything on screen is generated by code at start-up — **no model files, no image textures, no
downloaded assets.** Geometry is built with custom `BufferGeometry`, materials are patched with
procedural GLSL, terrain/vegetation/masonry are scattered from noise functions, and even the audio
is synthesised with the Web Audio API. (The gilt lettering on the tender is drawn to a `<canvas>`
at start-up; the page also pulls two Google fonts for the HUD.)

## Run it

Requires Node 18+.

```bash
cd highland-express
npm install
npm run dev          # http://localhost:5190
```

```bash
npm run build        # type-check + production build into dist/
npm run preview      # serve the production build
```

First load takes a few seconds while the terrain, 8 500 masonry blocks, ~8 500 trees and the
locomotive are generated (progress is shown on the loading card).

## What you'll see

A 76-second scripted opening, then free control:

1. Wide establishing shot of the glen, the viaduct, the river and the head-of-glen waterfall
2. Slow approach to the locomotive on the curve
3. Low tracking shot along the driving wheels — rods, cranks and Walschaerts valve gear
4. The train crosses the arches (seen from below the viaduct)
5. Pull-back and rise to show the scale of the structure
6. Final dramatic wide of the whole landscape — then the camera is yours

## Controls

| Input | Action |
| --- | --- |
| Drag / wheel / pinch | Orbit and zoom (taking over from the cinematic at any time) |
| `Space` | Pause / resume the train |
| `C` | Cycle camera: Cinematic → Orbit → Follow train |
| `F` / `O` | Follow camera / free orbit |
| `+` / `−` | Train speed |
| `W` (hold) | Whistle |
| `M` | Sound on / off (audio is created only after you ask for it) |
| `Q` | Switch graphics quality (High / Lite) — reloads the scene |
| `X` | Fullscreen |
| `R` | Replay the opening sequence |
| `H` | Hide the interface |

The bottom bar mirrors these controls and fades away when idle.

Dev helpers: `?cam=x,y,z,tx,ty,tz` starts in orbit at a pose, `?view=loco` opens an isolated
locomotive viewer, `?speed=` sets the cruising speed (m/s), `?s=` sets the start position along the
track (m).

## How it is built

```
src/
  main.ts                 bootstrap, render loop, HUD wiring, teardown
  core/
    stage.ts              renderer, composer (MSAA → bloom → final grade), shadow-frustum fitting,
                          dynamic resolution
    finalpass.ts          ACES tone map + sRGB + split-tone grade + vignette + grain in one pass
    fog.ts                height-aware fog replacing three's fog chunks (valley mist + sun scatter)
    shaders.ts            material patching helper, shared GLSL noise, wind sway
    noise.ts              seeded RNG, Perlin / fbm / ridged noise
    audio.ts              Web Audio synthesis: chuffs, rail clatter, whistle, wind, river, birds
  world/
    layout.ts             world layout constants (loop control points, viaduct, river, sun)
    track.ts              closed arc-length-parameterised spline, grades, cant, frames
    trackMesh.ts          rails (extruded profile), ballast, instanced sleepers / chairs / fishplates
    landscape.ts          terrain height model (bowl, hills, mountains, river glen, crags,
                          railway cuttings & embankments carved from the track)
    terrain.ts            5 stitched LOD rings, vertex colour, baked sun shadow + AO, detail shader
    viaduct.ts            parametric curved viaduct: battered wedge piers, conical vault stones,
                          spandrels, string course, balustrade — ~8 500 instanced dressed stones
    water.ts              river ribbon shader (flow, fresnel sky reflection, foam), rapids, falls
    flora.ts / vegetation.ts   procedural pines, Scots pines, birch/oak/rowan, heather, gorse,
                          bracken, grass, flowers, rocks — BatchedMesh with manual LOD + instancing
    ecology.ts            shared habitat masks (terrain colour and planting agree)
    lineside.ts           telegraph poles and wires, post-and-wire fence, semaphore signal
    sheep.ts              ~200 blackface sheep: boid flocking on the terrain, grazing, GPU-animated legs/head,
                          they stop and watch the train go by (and bleat, synthesised)
    sky.ts / (stage.ts)   sky dome with moving procedural clouds, PMREM environment
  train/
    locomotive.ts         boiler, smokebox, cab, backhead, cylinders, pilot… and the mechanism
    wheels.ts             spoked wheelsets with counterweights and crank pins
    tender.ts, carriage.ts   tender with coal heap; Victorian compartment coaches with lit interiors
    train.ts              places every vehicle on the spline from axle / bogie chords
    inst.ts, geo.ts, materials.ts, decals.ts   modelling toolkit and weathered paint shaders
  fx/
    particles.ts          depth-sorted billboard puffs (smoke/steam/mist), dust motes
    effects.ts            chuff-locked exhaust, cylinder cocks, safety valves, whistle, spray
  ui/
    camera.ts             cinematic director, orbit/follow rig, collision resolution
    hud.ts                interface, captions, keyboard
```

### Mechanical accuracy

Wheel angle is the single source of truth: `θ = distance ÷ driver radius`. Every moving part is
solved from it each frame, and rod lengths stay rigid:

* crank pins sit on each wheel (right leads the left by 90°),
* the main rod runs from the middle crank pin to a crosshead sliding on the cylinder axis
  (`z = pin.z + √(L² − Δy²)`), which drives the piston rod,
* coupling rods keep a parallelogram link between the three driving axles,
* Walschaerts gear: a return crank on the crank pin drives an eccentric rod whose foot is found
  by circle–circle intersection on the expansion link; the die block moves the radius rod; the
  combination lever joins crosshead and radius-rod motion to drive the valve rod.

Exhaust beats (four per driver revolution) come from the same wheel angle, so the smoke puffs and
the audio chuffs are phase-locked to the cranks. Rail-joint clatter is locked to distance
travelled. Vehicles are placed on the spline using chords between axle / bogie centres, so the
loco, tender and coaches follow curves, grades and superelevation without floating or drifting.

### Performance notes

* ~300–350 draw calls: all moving parts (wheels, rods, whole coach rake) use instanced batches driven
  by scene-graph nodes; static loco/tender meshes are merged per material.
* Trees and rocks are `BatchedMesh` instances with distance LOD; grass/shrubs are instanced per
  spatial cell and culled by distance.
* Terrain is five concentric LOD rings with stitched seams; shading detail fades with distance.
* Shadow cascade is a single map re-fitted every frame (snapped to texels); the terrain also has
  baked ridge shadows that fade in outside the dynamic region.
* Dynamic resolution scales the render target between 50 % and 100 % to hold the frame rate.

### Quality tiers and devices

The tier is picked automatically on start (coarse-pointer small screens, ≤4 GB RAM, ≤4 cores or a
mobile / integrated GPU → **Lite**) and can be forced with `?quality=lite|high` or the `Q` key
(the choice is remembered). Lite uses a ~75 % lighter terrain mesh, roughly 40 % of the planting,
a 2048 shadow map without tree shadows, no MSAA, a lower pixel-ratio cap and shorter draw
distances; dynamic resolution then adapts further. Portrait screens widen the field of view and
pull the cinematic close-ups back so the train stays in frame; controls grow to 44 px touch targets
and respect safe-area insets.

### Notes

* Needs a WebGL2 browser with `EXT_color_buffer_float` (any current desktop browser).
* Sound requires a click (browser autoplay policy). Positional audio follows the camera.
* Ambient occlusion is baked: concavity AO in the terrain vertex colours, contact-shadow decals under
  every tree and boulder, mortar-line / edge darkening on every masonry block, and grime gradients in
  the locomotive paint shaders.
